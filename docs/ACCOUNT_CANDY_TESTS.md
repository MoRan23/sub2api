## 糖果题测试

账号管理页的 OpenAI 账号菜单和批量操作栏提供“糖果题测试”。打开弹窗和手动刷新会实时读取各账号的上游模型目录，合并展示上游原始模型 ID，不受账号业务白名单或模型映射限制。选择一个模型与思考强度后开始，整批使用同一配置；不支持的平台、模型或档位明确跳过，不换账号或暗中调整模型。目录读取失败或为空的账号显示具体原因，不能从白名单补出模型。

目录查询最多同时处理 3 个账号，每账号最多等待 15 秒；大量账号需要分组等待，关闭弹窗会中断本次目录读取。历史及正在运行的批次仍可独立加载，每 5 秒的进度刷新不重复查询上游目录。创建批次时重新核对上游能力；未知档位能力只提供“跟随模型默认”。

题目固定为用户提供的糖果题，只有四项最少颗数参与判分：第 1 问固定 **32**，第 2 问自适应 **29**，第 3 问固定 **40**、自适应 **38**。模型不会收到这些答案。四项均能唯一识别时，全对为“正常”，有错为“异常”；缺项、矛盾、无法解析、缺少完成终态、超时及网络错误为“测试失败”。取法和证明不评分，也不用第二个模型判卷。

测试直接发送选中的上游模型 ID，不应用账号映射或旧 Codex 模型别名替换；使用该账号真实的 HTTP 协议适配、Lite、代理、TLS 和默认系统身份。业务请求原有的白名单和模型映射不变。测试会消耗上游额度，但不扣本项目用户余额或配额；正常、异常以及 401／403／429 都不会修改账号状态、调度、限流或冷却。必要的请求前 OAuth 刷新成功仍可通过 CAS 保存新凭据，刷新失败只记本次失败。每项最多发送一次推理请求，不自动重试或跟随 HTTP 重定向。

任务由 PostgreSQL 持久化，全服务跨实例最多并发 3 项，同账号串行，单项最长 20 分钟。关闭弹窗或刷新浏览器后继续运行；主动取消通常在下一次 5 秒心跳内停止。待执行项在重启后恢复，失去租约的运行项记为中断，不重放可能已发送的请求。

列表显示最新结果和独立的进行中状态，详情保留答案、最终正文、模型证据、用量和耗时。不保存推理过程、完整 SSE、凭据或请求头。每账号保留最近 5 条终态记录；活动批次中的条目直到批次结束才清理。批次原始统计保留，旧记录裁剪后分页使用 `retained_total`。

管理员接口使用现有认证和响应封装，完整前缀为 `/api/v1/admin`：

- `POST /accounts/candy-test-options`：`account_ids`，实时读取各账号上游模型目录与可确认的档位能力；逐账号返回结果或跳过原因。
- `POST /accounts/candy-tests`：`account_ids`、`model`、`reasoning_effort`、`idempotency_key`；同键同请求复用批次，不同请求返回 409。账号 ID 去重后执行。
- `GET /accounts/candy-tests/:batch_id`：分页读取进度和结果。
- `POST /accounts/candy-tests/:batch_id/cancel`：`{}` 取消整个批次，或以 `item_ids` 取消其中指定项。
- `GET /accounts/:id/candy-tests`：最近五次终态 `items` 和用于恢复正在运行批次的 `summary`。

相关接口禁止缓存；账号列表的 `candy_test` 摘要通过一次批量查询加载，并参与列表 ETag。

## 缓存退役边界

已移除本项目自建的目标票据缓存、后台采集、Cookie 包、采集代理轮换、出票代理绑定和切换开关，以及相应设置、状态接口、观测和页面。业务恢复使用账号原有代理；导入旧备份时忽略并剥离废弃配置，不能重新开启功能。

仍保留原有协议兼容：客户端 opaque `x-codex-turn-state`、原生 WS 元数据和 continuation、Messages 桥接自身的会话续传、来源摘要及已知跨账号／身份不匹配保护。这些不识别目标票形态，也不跨会话采集或注入目标缓存。Messages 的会话续传来自上游 `0584305e5`，不属于此次退役的自建采集系统。

三系统 UA、安装 ID、每日根、唯一 OAuth 授权、正常业务授权失败暂停、TLS 和遥测设置不变。上游返回模型及 safety-buffering 证据改由通用 `response_evidence` 承载；普通连接测试继续显示上游模型。未绑定账号的 OAuth 流程仍使用独立临时 Cookie 容器，避免共享授权会话。
