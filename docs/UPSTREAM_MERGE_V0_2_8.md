## 保留的本地规则与适配

OAuth 凭据仍只读取 `accounts.credentials`，沿用账号级刷新 CAS、永久授权失败暂停与重新授权恢复边界。系统识别只选择 UA、installation ID、TLS、会话根和遥测身份，不恢复分系统授权门控。管理查询不创建每日根。迟到授权失败不能对新授权写入账号运行态封禁。重新授权在同一账号事务内清理历史密码、SSO 和 Cookie 残留，保留非凭据配置并整体替换 provider token 元组。

HTTP 共享票据包继续绑定模型、协议、Cookie 和出票代理配置代次。账号关闭“使用出票代理”时，仍注入兼容票据和 Cookie，出口使用账号原代理。原生 WebSocket 旁路票据；WS→HTTP bridge 按真实 HTTP 发送处理。映射到 GPT-5.5 的 Lite 限制在选包、代理和身份冻结之前应用，发送末端不再单独改变协议决定。透传路径以实际发送模型作判断。

原始响应模型在公开模型名称改写前记录。SSE 成功终态先完成下游交付及票据、compact 提交，再取消和关闭上游响应体。native HTTP 使用统一取消及关闭生命周期，覆盖压缩响应、完成事件后没有 EOF、读取与关闭并发。bridge keepalive 不计为真实模型输出，客户端断开后的排空不触发业务重放。

保留本地官方模型目录及独立提示词，去重 GPT-6 Sol/Luna，合入 Opus 5.5、Grok 4.7、OpenCode Go。统一严格模型别名，日期后缀按真实日历校验，保留本地 Ultra 转发规则。直接模型目录查询与账号测试先统一系统、凭据及授权代次快照再构建缓存键；同身份复用缓存，跨系统或重新授权仍隔离。Claude 客户端版本同步接入全部请求路径，同一请求的 User-Agent 与 metadata 使用同一版本快照。Codex canonical UA 保留本地 TUI 规范及系统环境，同时吸收上游非法控制字符校验，避免早返回绕过身份归一。

设置与账号页面保留三系统身份、票据代理、遥测、完整性、礼金等配置。内容审查合入多引擎，同时保留本地白名单仅审计、提醒关键词和通知语义。新增 OAuth 调度倍率的 `null` 表示继承，`0` 保持显式值。备份、插件、渠道推理计价、邀请返利、配额及其他上游修复一并合入。

Wire 从 provider 源码重新生成，保留本地后台任务和退出清理，并加入 Claude 版本同步。代理备份关系恢复为多个主代理可共享一个备份代理，保留本地 `route_generation`；Ent 代码由 schema 重新生成。
