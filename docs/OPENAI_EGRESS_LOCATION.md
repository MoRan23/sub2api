# OpenAI OAuth 出口地域

OpenAI OAuth 的环境时区和搜索工具位置使用账号本次发送路由的出口地域。没有代理的账号探测当前服务实例的直连出口。继续由原有时区转换总开关、透传子开关控制；不改变每日固定根业务日期、residency、UA 或 TLS 模板。

## 探测与配置

出口 IP 通过账号代理访问已有探测地址获得，支持完整 IPv4 和 IPv6。地理查询由服务实例直连，查询参数是已探测到的明确 IP；不使用代理主机地址或客户端 IP。

默认使用 IPinfo 旧版公开 JSON 接口，不需要 token。按已发现的完整出口 IP 查询，不使用查询服务看到的本机 IP：

```yaml
security:
  proxy_probe:
    geo_lookup_url: "https://ipinfo.io/{ip}/json"
```

`{ip}` 必须在路径或查询参数中出现一次。IPinfo 的 `ip`、`country`（两位国家代码）、`region`、`city`、`timezone` 映射为完整地域；国家英文名称由国家代码转换，不额外联网查询。校验返回 IP、国家代码、完整城市地区以及 IANA 时区。查询有 5 秒超时、响应大小限制和限流冷却；不会跟随重定向，也不会把缺失字段拼接到其他来源的地域。

保留显式配置的查询 URL，兼容原有 ip-api JSON 响应结构。若旧部署已经写入 `geo_lookup_url: "http://ip-api.com/json/{ip}?lang=en"`，需改为上述 IPinfo 地址或删除该项以采用新默认值。原有 `security.proxy_probe.urls` 只负责发现出口 IP，其附带的城市不作为最终地域；即使探测接口返回 Portland，地域仍按 IPinfo 对该出口 IP 的查询结果决定。

匿名接口受服务方额度和可用性限制。遇到 HTTP 429 时遵守 `Retry-After` 并进入共享冷却，不自动切换到其他地域数据库。查询失败继续使用下述缓存或 Seattle 兜底，保持代理连通状态与地域查询状态分离。

## 缓存与回退

- 推理请求只读取进程内缓存，不同步联网探测。后台最多两个 worker、256 项队列、2,048 条路由记录，每分钟最多启动 30 次刷新。
- 完整结果有效 1 小时；刷新失败时，同一路由且未确认换 IP 的结果最多保留 24 小时。失败至少等待 5 分钟再尝试。
- 缓存按完整代理配置摘要隔离；直连缓存按服务实例隔离。配置改变使用新缓存键。重启不读取旧的无 TTL 延迟缓存作为地域依据。
- 首次请求、信息不完整、结果过期或新 IP 尚未解析时，使用 `US / Washington / Seattle / America/Los_Angeles`，并在观测中标明兜底。
- 管理页手动测试复用同一探测和地域缓存。连接成功、地域查询失败是两个独立结果；质量检查不会以缺省字段清空仍有效的同 IP 地域。

此机制主要面向固定出口。它测量的是同一路由访问探测地址的出口；对于按目标域名分流或每次连接随机更换出口的代理，不能保证探测地址和 OpenAI 使用同一个公网 IP。

## 请求与观测

请求冻结接收时间、环境来源资格和转换开关；选号后冻结发送路由与地域目标。同路由重试不随后台刷新改变目标，换路由仅重新应用本项目拥有的精确地域补丁。历史环境日期保持原值，本轮日期按冻结接收时间和目标时区计算。搜索文字、时间工具 `utc_offset` 和绝对时间戳不改写。

指纹观测的出口摘要解释转换依据；最终出站时区、城市和地区仍读取实际发送正文。关闭指纹采集不会关闭地域转换或后台地域缓存。

IP 管理页显示完整 IPv6、国家/地区/城市、时区、地域检测时间及失败原因。旧缓存缺少路由身份或时区时，视为地域尚未完成解析。
