# Codex 客户端遥测

后台「系统设置 → 网关服务」中的「Codex 客户端遥测」默认开启。它发送
Codex analytics 事件和 OTLP 性能指标，其中包含模拟客户端行为：这些模拟
事件不表示网关实际执行过工具、命令、文件修改或标题生成。

该开关独立于「每日固定根会话」和「采集指纹」。主请求的关联身份来自
最终出站请求；模拟子线程的标识仅用于遥测，不会改写请求或根池。
「指纹观测 → 客户端遥测」单独显示发送状态，端点返回成功仅表示发送成功。
最近 500 条摘要只保存在当前进程内存，重启会清空；多实例各自维护记录。

## 环境变量

| 变量 | 行为 |
| --- | --- |
| `CODEX_TELEMETRY_ENABLED` | 留空由后台设置控制；`false` 强制关闭，即使后台配置为开启。环境变量不能强制覆盖后台的关闭设置。 |
| `CODEX_STATSIG_API_KEY` | 可选 Statsig SDK key 覆盖，仅用于指标发送，不通过设置或观测 API 返回。 |

Compose 部署可在 `deploy/.env` 设置；直接运行二进制时设置进程环境。
修改环境变量需要重新创建容器或重启进程；后台开关即时作用于当前实例。
关闭时取消进行中的发送并丢弃排队任务与未汇总指标，重新开启不会补发。
已经发送的数据不能撤回。

发送沿用账号代理，禁止重定向；analytics 使用该账号 OAuth 鉴权，metrics
使用 SDK key。发送错误不会影响推理、计费或账号限流。管理摘要不保存
鉴权、SDK key、代理凭据、提示或响应正文。

事件和指标定义参考 [codex2api PR #666](https://github.com/james-6-23/codex2api/pull/666)
的 `8d959db`，已适配本项目最终出站身份与响应解析链路。支持 66 项指标定义，
按账号、客户端、模型等属性分别聚合。没有实际测量依据的服务器内部耗时
不会填入随机值；HTTP 请求不会产生 WebSocket 成功指标。每个物理尝试分别
计数，同一实际线程与 turn 的重试只产生一次结束事件。

遥测不会修补主请求缺失的身份。现有同步 HTTP→WS 等路径在没有客户端会话
身份时，最终出站可能没有 session/thread；此时记录跳过原因，不生成关联
主 turn 事件。是否关联以最终物理发送值为准，不能仅根据每日固定根开关推断。

## 只读管理接口

`GET /api/v1/admin/openai/telemetry-observations` 使用现有管理员认证。
可选参数：`account_id`（正整数）、`type`（`analytics` / `metrics`）、
`status`（`queued` / `sent` / `failed` / `dropped` / `cancelled` / `skipped`）、
`page`（默认 1）、`page_size`（默认 20，最大 100）。
接口返回实际/配置开关状态、强制关闭原因、队列计数和脱敏发送摘要；查询
不触发采集或上游发送。
