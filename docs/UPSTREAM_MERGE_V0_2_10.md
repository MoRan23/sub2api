## 冲突与兼容决策

### 网关与 WebSocket

吸收复合分组的模型归属、别名解析和连接级路由。连接建立后切换复合分组公开模型仍须重连；即使公开模型及上游映射不变，每一轮仍调用最新账号模型权限检查，账号权限撤销不能被相同映射绕过。拒绝的轮次不得写入上游，保留对应关闭码、重连提示和已转发次数断言。新增专项覆盖 passthrough 与 dedicated 两条路径。

### 风控与审计

新全局白名单 `cyber_policy_user_allowlist` 命中时优先采用上游仅审计规则。即使同时命中本地旧审计白名单，也不阻断、封号、记录违规哈希、封禁会话或发送通知，日志的违规次数为零。本地旧白名单单独命中时继续保留原审计、通知收件人与配置行为。真实上游拒绝仍沿用原协议响应。

异步审计任务保留请求判定时的仅审计标记；排队期间移除白名单不会把已允许的任务变为处罚。历史违规统计同时排除 `whitelist_allow`、`cyber_log_only`、`risk_control_log_only`，移除名单后不追罚历史审计事件。使用手动任务队列、模拟 SMTP 和隔离 PostgreSQL 覆盖同时命中、名单移除、通知抑制及历史统计。

### 服务装配与管理接口

Wire 源定义同时注入本地糖果测试与上游 Claude 重置额度查询服务，解决源定义后重新生成 `wire_gen.go`。保留分组申请、令牌缓存失效及 Codex 导出二次鉴权。接入只读接口 `GET /admin/accounts/:id/claude/reset-credits`、全局白名单设置字段及趋势参数 `metric=tokens|actual_cost`，保持后端 DTO、缓存键、路由和前端类型一致。

设置页自动合并遗留了已替换组件名 `OpenAIFastPolicyUserSelector`，已适配为本地共享的 `AdminUserMultiSelect`。新增回归验证 ID 去重、选择变更及保存序列化，并通过模拟 API 浏览器流程检查真实组件。

### 其他上游更新

完整吸收流式用量修复、工具名重写、Antigravity 保活、Sonnet 5.5、模型白名单映射修复，以及额度、趋势和客户端入口更新。OpenAI 分组生成配置移除 `model_catalog_json`；其他适用分组保留自定义目录配置。Claude-Code-only 分组保持限定客户端入口。
