# 注册邀请码与邀请返利

开启系统设置中的“邀请码注册”后，新用户可以使用以下任一有效邀请码完成注册：

- 管理员创建的一次性注册邀请码：注册成功时占用，使用后不可再次注册。
- 用户的返利邀请码：邀请返利功能开启、邀请人账号有效时可重复使用；注册成功时同时绑定该邀请人。

返利链接 `/register?aff=邀请码`（兼容 `aff_code` 参数）会自动填入注册页的邀请码输入框并校验。通过邮箱验证或第三方 OAuth 完成注册时，邀请关系继续保留。用户手动修改输入框后，异步校验或设置加载不会覆盖该输入。

注册接口继续使用 `invitation_code` 和 `aff_code`。开启邀请码注册时，显式填写的 `invitation_code` 优先；缺失时才使用 `aff_code`。显式无效的邀请码会返回错误，不使用另一个返利码放行。返利码作为注册凭证时，由该码确定邀请人，其他 `aff_code` 不会覆盖邀请关系。

返利码注册在同一数据库事务中完成用户创建和邀请人绑定，绑定失败会撤销用户创建。邀请人被禁用、删除或邀请码变更时，提交前会再次校验。两个命名空间出现同名码时，已有的一次性注册码保持原本的类型及使用状态规则。

关闭邀请返利功能后，返利码不能替代注册邀请码。注册总开关、邮箱验证、邮箱域名限制及既有账号登录规则继续生效。关闭“邀请码注册”时，返利码仍按原有规则用于绑定邀请关系。
