# 鹈鹕测试升级

新任务使用 `pelican-v1`，现有 `/candy-tests` 接口路径和数据库表名保持兼容。已生成的 HTML 从原始最终回复提取，只在详情接口返回；账号列表摘要不包含源码。前端在隔离的 iframe 中预览，不在服务端运行生成代码。

## 发布顺序

1. 停止所有旧版本应用实例及测试工作进程，避免滚动发布期间旧进程领取新任务。
2. 执行数据库迁移 `262_account_pelican_tests.sql`（应用启动时由现有迁移流程执行）。迁移取消未完成的旧糖果任务，清除租约，并结束对应批次；不会重新执行这些任务。
3. 启动新版本应用，再恢复入口流量。不要启动未包含本迁移对应代码的旧工作进程。

本次代码交付不执行部署或操作线上数据库。

## 历史兼容

- 旧糖果记录保留原有终态结果，不重新判题；历史、列表摘要及批次接口仅返回 `pelican-v1`。
- 旧批次 ID 返回不存在。复用旧幂等键会返回冲突，请为新测试生成新的键。
- 每账号最近 5 条的清理规则仅作用于鹈鹕记录。尚未整体完成的批次继续保留其所有结果。
- `generated` 仅表示完整请求中提取到了唯一 HTML 文档，不代表画面质量达标。无完整文档或包含多个不同完整文档为异常；执行、授权、超时和流错误仍是测试失败。

验证使用合成上游回复、临时 PostgreSQL/Redis 和本地 HTML，不发送收费模型请求。提示词中的“你不需要进行任何测试”只约束被测模型，不影响项目自身回归验证。
